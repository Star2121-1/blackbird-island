# 《黑鸟岛》VN 章节改编规范

给参与改编的智能体。先读这份，再读 `blackbird-vn/game/03_flow.rpy`（成品样例），然后动笔。

## 你要交什么

一个 `.rpy` 文件，里面**只有** `label chN:` 块（一章一块），块与块之间用 `jump chN+1` 串起来。
不要改别的文件。需要新证据／新可查点，写在文件末尾的注释里（见 §6），由主线程接线。

## 1. 体例

```
label ch7:
    call screen bb_card("第七章", "绣标", "一句不超过 20 字的副题", "十一月十八日", BB_SNAP("bg_hall_long.jpg"))
    scene bg_hall_long
    show spr_zhao as talker at bb_talk_r
    ZHAO "……"
    N "……"
    ME "……"
    jump ch8
```

- 一章开头必须是一张 `bb_card`，第五个参数是钉在卡片上的翻拍：`BB_SNAP("文件名.jpg")`，没有合适的就传 `None`。
- 说话人换人时补一行 `show spr_xx as talker at bb_talk_r`；旁白段不需要立绘。
- 一章 18～45 行。原文一章动辄一两百行，要压；压的办法是删，不是改写。
- 一条语句一行，不要反斜杠续行；单条不超过约 120 字。

## 3. 可用场景图

`bg_hangzhou`（杭州档案馆）、`bg_dock`（码头）、`bg_manor_ext`（庄园·从海上看）、
`bg_hall_long`（大厅·长桌）、`bg_hall_ring`（大厅·环形沙发）、
`bg_hall_table`（大厅·八仙桌）、`bg_study`（书房）、
`bg_east_wing`（东翼走廊）、`bg_east_wing_room`（东翼那一间房：铁床、防尘布、木匣）、
`bg_corridor`（一楼走廊与楼梯）、
`bg_shore`（礁石·退潮）、
`bg_bedroom_day`（客房·白昼）、`bg_bridge_night`（临东海大桥·雨夜，照片里的桥）。
写场景时从中选一个最贴的；同一章内换地点就换 `scene`。
大厅那三张按剧情分，撤换都写在终稿正文里，不要凭感觉：
长桌到第六章九点的钟声之前（终稿 119 那张长桌就是晚餐的桌，898 撤走它）→
环形沙发（终稿 898 起，含第七章"放在沙发扶手上"、第八章"放在矮木几上"）→
八仙桌（终稿 1543，第九章里当场撤换，此后不再回头）。
原著没有"餐厅"，也没有"船库"：这两张图造过又删了。晚餐就在大厅那张长桌上，
另起一间饭厅等于让同一张桌子在玩家眼里变成两个地点。
庄园从海上看是**白色**的（终稿 21"我看见一座白色的建筑物矗立在礁石之上"），
不是灰色哥特式。`bg_manor_ext` 和 `bg_dock` 画的是同一栋房子——重画其中一张，
要把另一张当参考图一起生成，否则玩家先在海面上看见它、再在码头上抬头看见它，就成了两栋。
新增一张要同时补三处，否则 `tools/test_content.py` 那一节会红：`tools/build_assets.py` 的 `BG_KEYS`、
`game/04_images.rpy` 的 `image bg_*`、`game/00_settings.rpy` 的 `BB_AMB_BY_BG`（漏了那张章节卡就是静音的）。

## 4. 铁规矩：措辞不改，只删不增

- 每句台词／旁白都要能在 `黑鸟岛-终稿.md` 里**逐字**对上（允许整段删、允许句内截断，不允许换词、不允许补写）。
- 全角叹号 `！` 一处都不许出现。
- 台词里不许出现阿拉伯数字：写 `二〇〇九年十一月十七日`，不写 `2009年11月17日`。
- 自检：`python blackbird-vn/tools/check_verbatim.py`。你写的那几章应当只出现"逐字可溯"，
  出现 `ADD`／`MISS` 就是你增改了，回去改成删。改到干净为止。

## 6. 需要新道具时

在文件末尾按这个格式列出来，别自己去动 `01_data.rpy`：

```
# NEED EV("cups", "八只杯", "一句简介。", "第九章")
# NEED SPOT("spot_cups", "陈默看到的那一句。", "cups")
```

`SPOT` 的第三个参数是要发的证据 id。主线程会把它们接进数据层和热点表。

## 7. 叙事红线

- 这是推理游戏，第八个名字到 ch14 之前不许出现，凶手到 ch20 之前不许点名。
- 沈南舟的儿子、临东海事件、"先杀后撞"这三件事的揭示顺序照原文，不要提前。
- 顾言笙的 2025 笔记只在日与日之间出现一次，用作"翻过一页"的呼吸口，不要插进岛内场景。
- 原文的克制来自短句和留白。宁可少给十行，不要把话说满。
