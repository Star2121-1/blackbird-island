# 黑鸟岛：筛子

一份没有结案的手稿。翻它的人是二〇二五年杭州的顾言笙；书里那座渡轮只开一趟的岛上，
待六天的是手稿的那个“我”——陈默。
这本书不许你指认谁——你赢的方式，是逼出多少沉默。

## 怎么开始

解压后直接运行，不需要安装：

| 平台 | 入口 |
| --- | --- |
| Windows | `blackbird.exe` |
| macOS | `blackbird.app` |
| Linux | `blackbird.sh` |

macOS 首次打开若被拦下，在「访达」里按住 Control 点应用 →「打开」。
Linux 先给启动脚本执行权限再运行：`chmod +x blackbird.sh && ./blackbird.sh`。
（`pc` 包是 Windows＋Linux 两用，里面没有 `blackbird.app`——macOS 请取 `mac` 包。）
（包的**根目录**里没有能直接点开的 `blackbird`；那个名字是启动脚本在内部调用的可执行体，
  在 `lib/…/blackbird` 和 `blackbird.app/Contents/MacOS/` 底下，不用直接碰。）

## 键位

| 键 | 作用 |
| --- | --- |
| 鼠标点击 / 空格 / 回车 | 继续下一句 |
| `Esc` / 鼠标右键 | 菜单：存档、读档、设置、帮助 |
| `Ctrl`（按住） | 快进——只跳**读过**的部分 |
| `Tab` | 跳过读过的句子（再按一次取消） |
| `.`（句点） | 一路快进到没读过的地方 |
| `PageUp` / 滚轮上 | 回看上一句（`PageDown` 回来） |
| 方向键 + 回车 | 对质时选中证据、举起；焦点回到「反　驳」，再按一次回车就抵上去 |
| `F1` | 游戏内的说明页（规矩＋键位） |
| 右上角「日志」 | 回看说过的话 |
| `S` | 截图（存到游戏目录，会弹一条提示） |

上面两条快进都受设置里那一格「允许跳过」管：它关着时，没读过的正文跳不过去；打开才一路快进。

游戏内按 `Esc` →「怎么读这份卷宗」有完整规则说明，第一次对质之前建议先看一眼。

## 界面说明

版面按 1920×1080 设计，所有元素留在 5% 安全区内；窗口任意缩放由引擎整体等比处理，
不会破坏对齐。设置页里没有字号和行距滑杆——全站是像素定宽的版面，字一放大图例、
证据轨、对白页就会被裁切。代价也写在这里：最小的那一行在 1920 宽时排的是 20 像素，
窗口只有 1280×720 时约合 13 像素，认得出字形但谈不上好读。
请把窗口留在 1600×900 以上，或使用系统缩放。

## 存档位置

Windows：`%APPDATA%\RenPy\blackbird_island_saves`
macOS：`~/Library/RenPy/blackbird_island_saves`
Linux：`~/.renpy/blackbird_island_saves`

这一串名字写死在 `config.save_directory` 里，不跟着你把游戏解压成什么文件夹名走——
改名、挪位置，存档还在原处。

## 配音

对质那五桌上，八个人说的**每一句**都有人声（41 句）；正文（说书那一路）不配音，纸上的字还是自己读。

为什么不"只挑关键几句配"：这本子的胜负写在"哪句话能被打断"上。只给有破绽的 21 句配音，
等于在可破的那几句头顶挂一盏灯——听哪句有人开口就抵哪句，四下机会足够，推理这一关直接空转。
所以整桌都出声，人声不标记哪一句可破。

- 音色：微软 edge-tts 的中文神经音色（Yunjian／Yunxi／Yunyang／Yunxia／Xiaoyi）。
  联网合成一次，落进包里的只有 mp3——游戏运行时不联网，也不需要装任何语音库。
- 六个人共用五副嗓子：方廷与王剑同为 Yunyang，靠音高与语速分开（+10Hz／+8% 对 −8Hz／−6%）。
- 只在第一次听到那句话时起，重听不重播；一轮收完就断。
- 41 条约 1.6 MB。不想听：`Esc` → 设置 → 「人声音量」拉到零。

## 授权

字体为思源宋体（Noto Serif SC）、思源黑体（Noto Sans CJK SC）与马善政毛笔楷书
（MaShanZheng），均为 SIL Open Font License 1.1；每个字体的授权文本与
`OFL-1.1.txt` 随包在 `game/fonts/` 下。
音效（海浪、穿堂风、窗外的雨、翻页、盖章）与全部 UI 贴图（纸面、章子、图标、遮没条）
由本项目程序化生成，没有一条是下载来的现成素材。
背景与人物立绘是按本书场景生成的 AI 原图，再由 `tools/build_assets.py` 统一洗图、抠边、
按头高取景。人声见上一节：微软 edge-tts 的公开神经音色合成，不是录音棚素材。

## 关于本作

改编自同名长篇推理小说《黑鸟岛》。游戏只做删节，不增写一句台词；
小说的结局问题——是谁——在这份手稿里同样不给答案。
