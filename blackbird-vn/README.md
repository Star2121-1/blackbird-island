# 黑鸟岛：筛子

一份没有结案的手稿。你扮演顾言笙，在一座渡轮只开一趟的岛上待六天。
这本书不许你指认谁——你赢的方式，是逼出多少沉默。

## 怎么开始

解压后直接运行，不需要安装：

| 平台 | 入口 |
| --- | --- |
| Windows | `blackbird.exe` |
| macOS | `blackbird.app` |
| Linux | `blackbird-linux/blackbird` |

macOS 首次打开若被拦下，在「访达」里按住 Control 点应用 →「打开」。
Linux 若提示没有执行权限：`chmod +x blackbird blackbird.sh`。

## 键位

| 键 | 作用 |
| --- | --- |
| 鼠标点击 / 空格 / 回车 | 继续下一句 |
| `Esc` | 菜单：存档、读档、设置、帮助 |
| `Ctrl` | 快进已读过的部分 |
| `Tab` | 快捷菜单 |
| 方向键 + 回车 | 对质时选中证据、举起、反驳 |
| `S` | 截图 |

游戏内按 `Esc` →「怎么读这份卷宗」有完整规则说明，第一次对质之前建议先看一眼。

## 界面说明

版面按 1920×1080 设计，所有元素留在 5% 安全区内；窗口任意缩放由引擎整体等比处理，
不会破坏对齐。设置页里没有字号和行距滑杆——全站是像素定宽的版面，字一放大图例、
证据轨、对白页就会被裁切。要看清小字请把窗口拉大或使用系统缩放。

## 存档位置

Windows：`%APPDATA%/blackbird/saves`
macOS：`~/Library/RenPy/blackbird/saves`
Linux：`~/.renpy/blackbird/saves`
